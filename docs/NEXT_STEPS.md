## 실행·검증

```bash
pip install -r requirements-dev.txt
python scripts/import_official_branches.py
python scripts/selfcheck.py
python -m pytest -q
streamlit run app.py
```

- **사업체 수:** 시군구 확정 통계표 대조와 정확한 출처 확인. 기존 값은 유지하지만 검증 완료로 표시하지 않습니다.

- **실제 거리:** 카카오 API 키 설정 후 실제 응답·주소 매칭·약관 확인. 네트워크 없는 예외 처리 테스트와 구분합니다.
